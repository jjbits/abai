# ornithopter

The example abaigram: an ornithopter over desert dunes with rock spires in
the way, whose only pilot is the agent attached to it. The person watches
in a browser; the agent reads the ship's senses through cells and flies
it through three setpoint knobs and a few capabilities. If the agent stops
reading or steering, the ship crashes.

The manual a coding agent follows to fly it is `../../MANUAL.md`. This
file is for a person reading the code.

```
npm install                            # links the stub and the harness from the workspace checkout
node src/main.ts                       # the game: prints its pid and the page's URL, waits for a pilot
node src/main.ts --demo                # the scripted flight abaikit check runs, headless and fast
node src/main.ts abai doctor --offline # the manifest, the content, the modes
npm test                               # the suite
npm run check                          # abaikit check .: conformance with no model
```

A pilot reaches the running game through the abai harness's MCP server.
From a shell, `node supervise.mjs --target <pid> prompt` attaches, makes
one call, prints the answer and exits; `cells`, `set`, `call`, `wait`,
`status`, `transcript` and `audit` are the other verbs. An MCP client
such as Claude Code runs the harness binary's `mcp` verb instead, or
`node src/main.ts abai mcp`, which starts the game inside the server.

## Layout

- `src/world.ts`: the seeded heightmap, the pad, the spires, the wall.
- `src/sim.ts`: the flight model and the control loop that holds the
  targets; it knows nothing of obstacles. `src/sensors.ts`: what the ship
  senses. `src/tuning.ts`: every number.
- `src/abai.ts`: the declaration. `src/channels.ts`: the wiring to the
  stub. `src/main.ts`: the entry. `src/demo.ts`: the scripted flight.
- `src/server.ts` and `public/`: the page, served on the loopback
  address; three.js draws the world the sim collides with.
- `abai/identity.md`: the pilot's prompt. `abaigram.yaml`: the manifest,
  generated by `node src/main.ts abai manifest > abaigram.yaml`.
